Project_A_BaselineReportService
================================

Baseline monolithic implementation of the operational reporting service.

This project simulates a heavy 'single endpoint' reporting service with synchronous exports, no caching or pre-aggregation, and no layered loading.

Quickstart
---------

1. ./setup.sh   # create venv and install deps
2. ./run_tests.sh

Outputs: results/ with results_pre.json and log_pre.txt
