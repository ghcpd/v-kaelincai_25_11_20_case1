Project_B_EnhancedReportService
================================

Enhanced operational reporting service demonstrating layered loading, simulated OLAP pre-aggregation, caching, incremental freshness metadata, concurrency control, cost-based throttling, circuit breaking, and async exports.

Quickstart
---------

1. ./setup.sh
2. ./run_tests.sh

Outputs: results/ with results_post.json and log_post.txt
