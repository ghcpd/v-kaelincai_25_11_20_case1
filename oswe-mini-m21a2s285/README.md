# UI/UX Improvement Experiment

This workspace contains two projects: baseline and enhanced transformations for a SaaS Ticket Detail Page. Tests and scenarios are in `test_scenarios.json` and can be run with `run_all.sh` which executes both project test suites then generates a comparison report.

Run the experiments:

  bash run_all.sh

Results are written to `results/` and project-specific `results/` directories. The comparison report is `compare_report.md`.
