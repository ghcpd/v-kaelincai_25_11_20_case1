# Project_A_BaselineTicketUI

Baseline transformer and tests.

Setup:

```bash
# On Linux/macOS
cd Project_A_BaselineTicketUI
bash setup.sh
bash run_tests.sh

# On Windows PowerShell
python -m venv .env
.\.env\Scripts\activate
pip install -r requirements.txt
pytest -q
```

Results are written to `results/results_pre.json` and `results/log_pre.txt`.
